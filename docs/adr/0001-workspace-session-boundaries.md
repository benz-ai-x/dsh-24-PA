# 一个助理预设，按发起会话隔离工作和权限

状态：accepted。依据：2026-10-05 用户确认「机器人包含 Lead 与工作区维护能力」，随后确认中文名24私助、英文名24PA。

24私助以工作区为配置和记忆归属，只提供一个对用户可见的助理 preset。飞书接入保留固定顶层 Session，本地可有多个同预设顶层会话；各自协调的 Worker 挂到实际父会话，工作账本保存发起入口与固定投递目标。这样同一会话可以交办和维护，本地结果仍回本地，飞书事项仍回飞书，恢复也保留原归属。

独立维护 preset 会使用户为普通维护切换角色；把全部对话并入一个飞书 Lead 则会混合本地历史与回传目标。采用单一 preset、多会话的边界，并由宿主核验入口、父子关系和工作区来决定工具权限。子 Agent 即使继承同一 preset 也只获得其职责允许的工具；配置和 JSON 写入仅向有维护权限的本地顶层会话开放。

产品更名只改变展示名称。现有插件、preset、会话、工具和数据路径标识保持兼容；若原会话被用户改成其他 preset，保留历史并建立正确的新入口，不重写旧会话身份。智能业务 Schedule 继续绑定固定飞书接入顶层会话，原生 child 不挂计划。
