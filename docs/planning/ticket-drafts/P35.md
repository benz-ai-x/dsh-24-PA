## What to build

主人询问历史决定或今天待收尾事项时，得到带审核依据的笔记，以及任务、日历、等待和待审汇总。

**功能 PR：** F11 · 审核笔记的行动与综合查询（同组：P34、P35）。本票沿用所属功能分支及 PR；同组前置依据该分支的提交与通过的验收推进，跨组前置等待功能合并。本票在所属功能合并且验收通过后关闭。

边界：P16/P24 是已有概览与晨报入口，P23/P33 提供新增的等待和审核事实。

覆盖父规格用户故事：9, 31, 32, 37, 62。对应测试组：T02, T03, T10, T12。

通过真实 dsh 装配、会话与隔离 PostgreSQL 验证用户可见及持久结果；仅替换模型、外部网络和时钟等边界。依赖内部具体函数调用顺序的断言不作为验收。

## Acceptance criteria

- [ ] 让笔记索引引用具体版本、日期和审核状态；引用为已确认事实前核验当前有效性。
- [ ] 未审核、已变更或 unknown 显式说明，不能因曾通过或反复引用而变成最新确定事实。
- [ ] 把等待项与待审队列加入已有今日概览及晨报，缺数据注明，不虚报零事项。
- [ ] 给出能打开的原稿/文档/任务链接，完整会话历史不默认拼接。
- [ ] 测试同一决定有多个版本、审核失效、同步失败和全类事项汇总。
