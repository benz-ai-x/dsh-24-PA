## What to build

主人询问历史决定或今天待收尾事项时，得到带审核依据的笔记，以及任务、日历、等待和待审汇总。

**功能 PR：F11 · 审核笔记的行动与综合查询**。本组 2 张实施票共用一个功能分支及 PR，一个 PR 交付一个可用功能，不按单票建 PR。

同组前置在该功能分支已有提交且验收通过即可继续，前置票可保持打开；跨组代码依赖须等对应功能合并并通过验收。本票在所属功能合并且验收通过后关闭。

该功能合并前置：F07 多页笔记与集中复核、F10 会议资料与纪要行动。

**依赖理由：** P16/P24 是已有概览与晨报入口，P23/P33 提供新增的等待和审核事实。

**覆盖规格：** 用户故事 9, 31, 32, 37, 62；测试组 T02, T03, T10, T12。

**验证边界：** 使用真实 dsh Loader、原生 Session/Agent 与隔离 PostgreSQL；仅替换模型、外部网络和时钟。观察真实工具执行、持久状态及最终用户结果，不以模型自述或内部调用顺序代替验收。构建产物、权限、重复、部分失败、重启和必要迁移/恢复说明随本票交付；相关真实飞书/模型验证另记实测或未验证状态。

## Acceptance criteria

- [ ] 让笔记索引引用具体版本、日期和审核状态；引用为已确认事实前核验当前有效性。
- [ ] 未审核、已变更或 unknown 显式说明，不能因曾通过或反复引用而变成最新确定事实。
- [ ] 把等待项与待审队列加入已有今日概览及晨报，缺数据注明，不虚报零事项。
- [ ] 给出能打开的原稿/文档/任务链接，完整会话历史不默认拼接。
- [ ] 测试同一决定有多个版本、审核失效、同步失败和全类事项汇总。
