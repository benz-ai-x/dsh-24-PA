## Acceptance criteria

- [ ] 按明确页序识别多页，检查漏页、跨页重复和段落顺序，不因批次重试重复拼接。
- [ ] 从保真原图生成区域裁片，保存坐标变换并区分可靠/估计/页级引用。
- [ ] 图示保留原图与文字说明；数字、人名、英文缩写、日期、否定、勾选突出复核。
- [ ] 自报置信度不当概率；不清内容保留未知，预算/并发到限暂停并保留已完成页。
- [ ] 用代表性样本比较单页基线和增强结果；不新增第二套模型 runtime 或默认全量双模型 OCR。
