## What to build

F09 周期服务的晨报（morning）与晚间复盘（evening）增加语音版投递：`digestBuild` 渲染文本后，经本机 TTS（macOS `say`＋ffmpeg 转 opus）合成 ogg 语音，以 bot 身份经 `lark-cli im +messages-send --audio` 发送**原生语音消息**到主人飞书，紧跟一条全文文本兜底。发送链路已真机验证（[F19 研究](../../research/F19-晨报复盘语音投递实现研究.md)，message_id `om_x100b635…`）。

交付内容：

1. **outbox 扩展**：`kind` 增加 `'audio'`（代码层类型扩展，无 DDL 枚举变更）；行内只存正文文本，投递时现场合成（自包含可重放）；`sendOutbox` 加 audio 分支（合成→cwd 相对路径→`--audio`＋幂等键）。
2. **TTS 模块**：接口化，首版 macOS 适配器（say→aiff→ffmpeg libopus→ogg）；命令存在性预检，缺失时降级发文本＋告警，不中断服务。
3. **开关面**：`digest_plan` 加 `voice boolean default false`（迁移）；`digest_enable` 入参与 `digest_control` 扩展 voice on/off，支持「早语音晚文本」的 per-plan 粒度。
4. **口播变体与长文上限**：语音正文剥离 syncedAt/数据缺失清单等元数据行；超限（≤1200 字）截断并在语音内播报截断提示；快照测试守护。
5. **指南**：初始化指南补 macOS 宿主（say）＋ffmpeg 前置项与诊断口径。

**功能 PR：F19 · 晨报复盘语音投递**。单票单 PR。

**覆盖规格：** 用户故事 126；测试组随规格 1.8 落版时定（outbox audio 分支、口播变体快照、截断、降级诊断为必测项）。

**验证边界：** 发送侧以 lark-cli 1.0.87 真机实测为准（bot 身份 `--audio` 成功；幂等键 1 小时去重；cwd 相对路径约束）。超长音频平台接受度、wecom 通道语音、lark-cli 1.0.97 升级差异为实施期回归项。macOS 宿主依赖（say）写入指南与诊断，实例迁移 Linux 需换 TTS 适配器（接口已预留）。

## Acceptance criteria

- [ ] morning/evening digest 开启 voice 后，到点主人飞书收到原生语音消息（bot 身份），随后收到全文文本兜底。
- [ ] 语音为本机合成的 opus/ogg（say＋ffmpeg）；命令缺失时投递降级为文本并有可观测告警，服务不中断。
- [ ] 超长正文截断到上限并播报截断提示；口播变体不含元数据行（快照测试）。
- [ ] `digest_control` 可调 voice on/off；迁移不丢既有 digest 计划与 occurrence 历史。
- [ ] outbox audio 行支持重试/重放（幂等键语义），实例重启后未投递行仍可投递。
- [ ] `notifyChannel='wecom'` 时语音降级文本并告警（wecom 语音 parity 后置）。
- [ ] 文档同步：SPEC 1.8（故事 126）、初始化指南前置项、工单索引与 PR 交付计划。
