## What to build

主人在同一24私助会话中修改和重载 AGENTS.md，用自然语言发起接入检查，再到只读面板查明生效配置和真实缺项。

**功能 PR：F01 · 工作区助理与随手记**。本组 5 张实施票共用一个功能分支及 PR，一个 PR 交付一个可用功能，不按单票建 PR。

同组前置在该功能分支已有提交且验收通过即可继续，前置票可保持打开；跨组代码依赖须等对应功能合并并通过验收。本票在所属功能合并且验收通过后关闭。

该功能合并前置：无。

**依赖理由：** P01 提供工作区和配置解析/生命周期；本票让维护者通过真实原生会话完整完成修改与验证，不依赖日常业务。

**覆盖规格：** 用户故事 101, 102, 103, 111, 113, 115, 116, 117, 118；测试组 T14, T15, T17, T20。

**验证边界：** 使用真实 dsh Loader、原生 Session/Agent 与隔离 PostgreSQL；仅替换模型、外部网络和时钟。观察真实工具执行、持久状态及最终用户结果，不以模型自述或内部调用顺序代替验收。构建产物、权限、重复、部分失败、重启和必要迁移/恢复说明随本票交付；相关真实飞书/模型验证另记实测或未验证状态。

## Acceptance criteria

- [ ] 本地顶层24私助会话关联已选工作区，协调与维护使用同一 preset；按真实入口与父子关系授予原生文件及配置工具。已有规则和非配置块内容保留，不增加配置表单。
- [ ] 配置变更经 schema、路径、profile、owner、资源与 Worker/模型引用校验后应用，结果展示差异和生效摘要；坏配置保留最近有效值并说明错误。
- [ ] 秘密只允许凭据/环境引用；面板、聊天和诊断仅返回引用名及是否提供。飞书接入、Worker 与其他未授权会话无法使用维护写工具，继承同一 preset 不能绕过检查。
- [ ] 普通配置重载不丢已有 WorkItem 和原生会话；身份/工作区变更在活动工作存在时明确阻止或先完成安全停机，不能静默改写历史授权。
- [ ] 验证实际原生维护输入→文件修改→校验重载→新会话规则生效，以及坏配置、重复重载与已有工作保留；维护输出不发飞书。
- [ ] 只读飞书接入页展示 CLI 路径/版本、固定 profile、主人与 CLI 用户、令牌核验、资源配置/可读性、机器人最近收发、凭据是否提供、配置来源/生效时间/检查时间及未重载变化。
- [ ] 接入检查由本人按需发起，不创建飞书对象；普通页面刷新只读诊断状态。profile 缺失不切到其他身份，未验证或身份不匹配时不读取资源，长连接启动/平台接受/可读/可写不得相互冒充。
- [ ] 验证尚未检查、缺 CLI、缺 profile、身份不匹配、单资源拒绝、配置未重载和检查失败，使用 SVG/文字/颜色区分状态；首个可用面板具备对话主入口和可访问页签，后续页面随所属业务启用。
