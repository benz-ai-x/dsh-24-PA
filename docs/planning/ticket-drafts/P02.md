## Acceptance criteria

- [ ] 用受控配置或一次性配对核验应用、租户、主人与私聊，不采用首次发消息即成为主人。
- [ ] 固定一个飞书 CLI profile，检查用户与机器人身份、允许的目录/清单/日历配置和基本授权状态。
- [ ] 一个完整 SDK 长连接处理器接收消息与按钮；在时限内先持久化最小 Inbox 再 ACK，PG 失败不报已接收。

- [ ] 热重载不增加第二消费者；覆盖错租户、错主人、重复事件、提交后重启和发送失败；此票不需要模型对话。
