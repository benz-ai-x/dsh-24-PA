## What to build

主人完成固定 profile 绑定，私聊发送状态指令后收到可追踪确认；未绑定主体不能使用助理。

**功能 PR：F01 · 工作区助理与随手记**。本组 5 张实施票共用一个功能分支及 PR，一个 PR 交付一个可用功能，不按单票建 PR。

同组前置在该功能分支已有提交且验收通过即可继续，前置票可保持打开；跨组代码依赖须等对应功能合并并通过验收。本票在所属功能合并且验收通过后关闭。

该功能合并前置：无。

**依赖理由：** 复用 P01 的真实宿主生命周期和 PG 连接/迁移。

**覆盖规格：** 用户故事 1, 3, 4, 87, 98；测试组 T01, T07, T14。

**验证边界：** 使用真实 dsh Loader、原生 Session/Agent 与隔离 PostgreSQL；仅替换模型、外部网络和时钟。观察真实工具执行、持久状态及最终用户结果，不以模型自述或内部调用顺序代替验收。构建产物、权限、重复、部分失败、重启和必要迁移/恢复说明随本票交付；相关真实飞书/模型验证另记实测或未验证状态。

## Acceptance criteria

- [ ] 用受控配置或一次性配对核验应用、租户、主人与私聊，不采用首次发消息即成为主人。
- [ ] 固定一个飞书 CLI profile，检查用户与机器人身份、允许的目录/清单/日历配置和基本授权状态。
- [ ] 一个完整 SDK 长连接处理器接收消息与按钮；在时限内先持久化最小 Inbox 再 ACK，PG 失败不报已接收。
- [ ] 状态响应经持久 Outbox 发送并保存消息标识；重复事件不会重复建立绑定或确认工作，结果未知可见。
- [ ] 热重载不增加第二消费者；覆盖错租户、错主人、重复事件、提交后重启和发送失败；此票不需要模型对话。
- [ ] 固定 SDK 版本实测 handler 等待与 ACK 时序、消息/卡片完整订阅、CLI 续期与授权失效；不并行启动第二个 CLI 事件消费者，不创建竞争令牌刷新器。
