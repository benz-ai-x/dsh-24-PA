**功能 PR：** F02 · 多会话工作台（同组：P04、P05、P06、P07、P36）。本票沿用所属功能分支及 PR；同组前置依据该分支的提交与通过的验收推进，跨组前置等待功能合并。本票在所属功能合并且验收通过后关闭。

覆盖父规格用户故事：38, 39, 40, 41, 42, 43, 44, 47。对应测试组：T04。

通过真实 dsh 装配、会话与隔离 PostgreSQL 验证用户可见及持久结果；仅替换模型、外部网络和时钟等边界。依赖内部具体函数调用顺序的断言不作为验收。

## Acceptance criteria

- [ ] 提供新建、重命名、列表、查看、切换和返回上一个会话；同名提供选择，名称映射真实 Session。
- [ ] 列表显示当前标记和各会话状态；查看使用冷安全读取，不批量激活所有历史 Agent。
- [ ] 切换原子保存当前/上一个指针后确认，后续输入目标固定；所有 A–E 始终使用同一飞书 profile。
- [ ] 切换不 dispose 或取消原工作；A 的完成卡注明来源，不改变当前 B，并能选择查看或切换 A。
- [ ] 按配置限制模型并发，允许五个会话均有未完成工作；覆盖运行中 A→B→A、同名和无权目标。
