## What to build

主人和部署者能看到哪些能力可用、识别为何暂停、最近同步情况及运行成本。

**功能 PR：F12 · 运行维护与数据恢复**。本组 3 张实施票共用一个功能分支及 PR，一个 PR 交付一个可用功能，不按单票建 PR。

同组前置在该功能分支已有提交且验收通过即可继续，前置票可保持打开；跨组代码依赖须等对应功能合并并通过验收。本票在所属功能合并且验收通过后关闭。

该功能合并前置：F11 审核笔记的行动与综合查询。

**依赖理由：** P30 提供实际视觉工作与预算对象，P21/P24 提供能验证独立降级的两类提醒。

**覆盖规格：** 用户故事 92, 93, 97, 98, 100, 101, 102, 104；测试组 T15, T16, T17, T18。

**验证边界：** 使用真实 dsh Loader、原生 Session/Agent 与隔离 PostgreSQL；仅替换模型、外部网络和时钟。观察真实工具执行、持久状态及最终用户结果，不以模型自述或内部调用顺序代替验收。构建产物、权限、重复、部分失败、重启和必要迁移/恢复说明随本票交付；相关真实飞书/模型验证另记实测或未验证状态。

## Acceptance criteria

- [ ] dsh 管理面板展示工作区、配置版本、PG、入站、发送、CLI、模型、同步、事项状态、只读记忆查询和原生维护入口；日常交办、拍照、审核仍通过飞书。
- [ ] 授权失效引导重新授权，模型或识别预算用尽只暂停对应工作，固定提醒继续。
- [ ] 统计输入页数/裁片、模型调用、重试、队列延迟和待核对操作，输出可测费用及限额状态。
- [ ] 列明普通模型输入与额外日志外传、保留期限以及全局开关对同 Host 的影响；凭据不进入诊断。
- [ ] 重载释放旧消费者，持续异常才通知；完全离线依赖独立服务器监控，测试降级、预算和恢复。
