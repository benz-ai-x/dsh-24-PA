## What to build

主人提交实际会后文字材料，获得飞书纪要，并选定行动项创建任务或日程。

**功能 PR：** F10 · 会议资料与纪要行动（同组：P26、P27）。本票沿用所属功能分支及 PR；同组前置依据该分支的提交与通过的验收推进，跨组前置等待功能合并。本票在所属功能合并且验收通过后关闭。

边界：P14 提供纪要文档；P11 及其任务写入前置提供两类行动的创建与回执，无需先有完整任务编辑。

覆盖父规格用户故事：27, 28, 29。对应测试组：T03, T13。

通过真实 dsh 装配、会话与隔离 PostgreSQL 验证用户可见及持久结果；仅替换模型、外部网络和时钟等边界。依赖内部具体函数调用顺序的断言不作为验收。

## Acceptance criteria

- [ ] 以用户提供或明确授权的材料生成纪要、决定、疑问与行动建议，资料不足不编造讨论。
- [ ] 文档和候选行动分别保存，候选包含出处、责任人/日期原话及未知项。
- [ ] 只对选定且信息足够的行动执行对应授权，保存到原文与外部对象的关联。
- [ ] 重复选择返回已有对象，创建结果未知先核对；纪要生成成功不等于行动已执行。
- [ ] 交付可供手写链复用的候选行动选择/执行契约，验证部分选择与任务/日程失败恢复。
