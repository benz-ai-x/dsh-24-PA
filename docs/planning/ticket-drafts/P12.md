## What to build

主人指定对象和时间安排会议，机器人定位正确联系人并完成获授权的邀请。

**功能 PR：F04 · 日程与会议安排**。本组 3 张实施票共用一个功能分支及 PR，一个 PR 交付一个可用功能，不按单票建 PR。

同组前置在该功能分支已有提交且验收通过即可继续，前置票可保持打开；跨组代码依赖须等对应功能合并并通过验收。本票在所属功能合并且验收通过后关闭。

该功能合并前置：F03 任务与项目清单。

**依赖理由：** 必须有 P11 的真实日程写入、改期和回执。

**覆盖规格：** 用户故事 7, 24；测试组 T01, T03。

**验证边界：** 使用真实 dsh Loader、原生 Session/Agent 与隔离 PostgreSQL；仅替换模型、外部网络和时钟。观察真实工具执行、持久状态及最终用户结果，不以模型自述或内部调用顺序代替验收。构建产物、权限、重复、部分失败、重启和必要迁移/恢复说明随本票交付；相关真实飞书/模型验证另记实测或未验证状态。

## Acceptance criteria

- [ ] 在允许范围解析联系人、忙闲、时区和地点；同名或不确定对象必须澄清。
- [ ] 列出最终参会人和时间，依据明确邀请指令执行，不因日历建议自动发送邀请。
- [ ] 复用日程操作回执和幂等核对，返回真实会议链接及未成功的部分。
- [ ] 改期/取消涉及他人时说明影响并执行明确指令；不假装未读取到的忙闲可用。
- [ ] 测试错人防护、部分邀请失败及响应丢失，不产生未经授权的额外邀请。
