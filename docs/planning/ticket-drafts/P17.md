- [ ] 基于用户提供的目标/行程输出子任务和先后关系，区分已知与待澄清信息。

- [ ] 项目进展来自实际任务状态，展示剩余工作和下一步，不从摘要推断完成。
- [ ] 支持出行、办事、采购、续期等清单，但不订票、付款或自动对外提交。
- [ ] 测试部分采纳、重复采纳、延期后的项目进展和个人清单变更。
