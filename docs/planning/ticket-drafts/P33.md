## What to build

主人可集中查看待审核/需修改笔记，进入原版本继续处理，或稍后提醒、暂停。

**功能 PR：F07 · 多页笔记与集中复核**。本组 2 张实施票共用一个功能分支及 PR，一个 PR 交付一个可用功能，不按单票建 PR。

同组前置在该功能分支已有提交且验收通过即可继续，前置票可保持打开；跨组代码依赖须等对应功能合并并通过验收。本票在所属功能合并且验收通过后关闭。

该功能合并前置：F05 个人提醒与免打扰、F06 手写笔记整理与人工审核。

**依赖理由：** P32 给出可靠当前审核状态；P21 提供有界通知策略。

**覆盖规格：** 用户故事 63, 77, 78；测试组 T09, T12。

**验证边界：** 使用真实 dsh Loader、原生 Session/Agent 与隔离 PostgreSQL；仅替换模型、外部网络和时钟。观察真实工具执行、持久状态及最终用户结果，不以模型自述或内部调用顺序代替验收。构建产物、权限、重复、部分失败、重启和必要迁移/恢复说明随本票交付；相关真实飞书/模型验证另记实测或未验证状态。

## Acceptance criteria

- [ ] 列出本人待审核、需修改和待重新审核对象，链接当前草稿及指定版本。
- [ ] 完成审核后移出对应待审状态，更新失败与审核失败分开显示。
- [ ] 提醒绑定笔记及版本，复用静默/限频，旧版本提醒不得继续催审。
- [ ] 稍后/暂停只改变提醒，不更改审核决定；查看或继续其他 WorkItem 后仍作用于原笔记与版本。
- [ ] 测试多份笔记、长期待审、审核与提醒竞争及重启恢复。
