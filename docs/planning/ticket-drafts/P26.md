## What to build

主人为指定会议要求会前准备，获得上次决定、待确认问题及相关资料出处。

**功能 PR：F10 · 会议资料与纪要行动**。本组 2 张实施票共用一个功能分支及 PR，一个 PR 交付一个可用功能，不按单票建 PR。

同组前置在该功能分支已有提交且验收通过即可继续，前置票可保持打开；跨组代码依赖须等对应功能合并并通过验收。本票在所属功能合并且验收通过后关闭。

该功能合并前置：F09 每日规划与定期回顾。

**依赖理由：** P14 提供资料读取，P24 及其日历查询前置提供真实会议状态、定时推理和去重；已有会议即可准备，无需先能发出邀请。

**覆盖规格：** 用户故事 26, 32；测试组 T03, T10。

**验证边界：** 使用真实 dsh Loader、原生 Session/Agent 与隔离 PostgreSQL；仅替换模型、外部网络和时钟。观察真实工具执行、持久状态及最终用户结果，不以模型自述或内部调用顺序代替验收。构建产物、权限、重复、部分失败、重启和必要迁移/恢复说明随本票交付；相关真实飞书/模型验证另记实测或未验证状态。

## Acceptance criteria

- [ ] 绑定具体会议、准备时间和允许的资料范围，复用智能定时工作。
- [ ] 检索授权备忘/任务和上次纪要，生成议程与有出处的问题清单；没有材料如实说明。
- [ ] 生成或发送前复查会议状态，取消/改期调整准备计划，不发送过时准备包。
- [ ] 结果标注具体会议和 WorkItem，由 Lead 汇报；点击可查看资料，不中断其他 Worker。
- [ ] 测试资料缺失、权限不足、会议变化及生成失败后的有用时段恢复。
