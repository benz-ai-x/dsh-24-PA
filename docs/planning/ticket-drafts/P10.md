## What to build

主人查询今天或本周安排，获得完整的授权日历结果、冲突与数据新鲜度。

**功能 PR：F04 · 日程与会议安排**。本组 3 张实施票共用一个功能分支及 PR，一个 PR 交付一个可用功能，不按单票建 PR。

同组前置在该功能分支已有提交且验收通过即可继续，前置票可保持打开；跨组代码依赖须等对应功能合并并通过验收。本票在所属功能合并且验收通过后关闭。

该功能合并前置：F03 任务与项目清单。

**依赖理由：** 需要已可委派的日程 Worker 和按需记忆读取；日历同步不依赖任务写入。

**覆盖规格：** 用户故事 9, 22, 62, 92；测试组 T02, T03。

**验证边界：** 使用真实 dsh Loader、原生 Session/Agent 与隔离 PostgreSQL；仅替换模型、外部网络和时钟。观察真实工具执行、持久状态及最终用户结果，不以模型自述或内部调用顺序代替验收。构建产物、权限、重复、部分失败、重启和必要迁移/恢复说明随本票交付；相关真实飞书/模型验证另记实测或未验证状态。

## Acceptance criteria

- [ ] 只读取选定日历，正确展示时区、全天事件、重复实例及取消状态。
- [ ] 同步使用完整分页/增量水位；时间范围截断不能当完整日历，游标失效可重建。
- [ ] 事件仅触发刷新，并有有界补偿读取；持久保存最近成功和缺失范围。
- [ ] 读取失败返回资料缺失或过期状态，不能回答没有会议；无权对象明确拒绝。
- [ ] 验证忙闲、冲突、分页超量、改期/取消及授权失效。
