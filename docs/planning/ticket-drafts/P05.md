## Acceptance criteria

- [ ] 持久保存平台消息到 Session/工作对象的路由，卡片动作校验主体、对象、版本和有效期。
- [ ] 显式目标和引用目标冲突时澄清；未知引用、过期或越权动作不得回退投到当前会话。
- [ ] 路由和切换按聊天串行提交；自然语言目标尚未确定时记录待定路由，后续无明确目标输入等待。
- [ ] 路由确定后不因切换、重启或后台完成而改变；跨切换迟到事件有歧义时暂停待选。
- [ ] 覆盖 B 中回复 A、重启后点击旧卡、重复动作、并发切换与事件乱序。
