## What to build

主人设置一个明确时间的提醒，到期获得模板卡片，并能完成、稍后或取消。

**功能 PR：F05 · 个人提醒与免打扰**。本组 4 张实施票共用一个功能分支及 PR，一个 PR 交付一个可用功能，不按单票建 PR。

同组前置在该功能分支已有提交且验收通过即可继续，前置票可保持打开；跨组代码依赖须等对应功能合并并通过验收。本票在所属功能合并且验收通过后关闭。

该功能合并前置：F02 并行事项与记忆维护。

**依赖理由：** P05 保证提醒控制卡固定目标，P15 提供本人时间与静默偏好；发送链路和原生 Worker 由前置提供。

**覆盖规格：** 用户故事 54, 55, 59, 64；测试组 T09。

**验证边界：** 使用真实 dsh Loader、原生 Session/Agent 与隔离 PostgreSQL；仅替换模型、外部网络和时钟。观察真实工具执行、持久状态及最终用户结果，不以模型自述或内部调用顺序代替验收。构建产物、权限、重复、部分失败、重启和必要迁移/恢复说明随本票交付；相关真实飞书/模型验证另记实测或未验证状态。

## Acceptance criteria

- [ ] Lead 委派提醒 Worker，确认时间、时区和内容后保存规则；调用 dsh 公开时间创建能力，不自己写时间引擎。
- [ ] 到期以 PG 发生实例和 Outbox 发送，模型不可用仍能工作；显示实际平台接受状态。
- [ ] 完成、稍后、取消绑定原规则和版本；重复按钮不创建多份延后实例。
- [ ] 每次触发与发送有稳定幂等身份，网络未知先核对；仅标平台接受，不推断已读/完成。
- [ ] 测试模型关闭、重启、重复领取、响应丢失和取消/发送竞争。
