## Acceptance criteria

- [ ] 偏好保存明确来源与有效期，支持查看、修改和删除，不从猜测自动生成长期事实。
- [ ] 记录 IANA 时区及用户表达，临时休假到期自动失效而不覆盖永久偏好。
- [ ] 各 Session 按需读取同一偏好事实，缓存更新不拼接全部聊天历史。
- [ ] 提供其他业务可调用的当前有效偏好读取契约；消费方在自己的票中验证遵守。
- [ ] 测试重启、到期、删除、并发修改和无权主体，不把默认建议伪装为已确认偏好。
