## What to build

主人发送一页手写笔记，得到原文转写、整理内容、疑点和原稿链接组成的飞书草稿。

**功能 PR：** F06 · 手写笔记整理与人工审核（同组：P28、P29、P31、P32）。本票沿用所属功能分支及 PR；同组前置依据该分支的提交与通过的验收推进，跨组前置等待功能合并。本票在所属功能合并且验收通过后关闭。

边界：P28 提供原稿，P14 提供文档创建与回读；这是最早可演示的手写整理闭环。

覆盖父规格用户故事：65, 70, 74, 75, 76。对应测试组：T11。

通过真实 dsh 装配、会话与隔离 PostgreSQL 验证用户可见及持久结果；仅替换模型、外部网络和时钟等边界。依赖内部具体函数调用顺序的断言不作为验收。

## Acceptance criteria

- [ ] 通过 dsh 视觉模型和附件识别，验证实际路由支持图像；模型不支持时返回能力状态。
- [ ] 转写、摘要、AI 建议、未知项和候选行动分离，相对日期保留原话与解释依据。
- [ ] 使用可核验模板写草稿，明确尚未经人工审核；正文和资源回读完整后才发送待处理链接。
- [ ] 每个识别/写入阶段保存恢复依据与模型版本，重试不重复创建文档。
- [ ] 演示真实单页混排输入；本票只生成候选，不提供未经实现的人工批准能力。
