## What to build

主人在忙碌会话中追加普通工作、明确补充或停止当前工作，并看到真实影响。

**功能 PR：** F02 · 多会话工作台（同组：P04、P05、P06、P07、P36）。本票沿用所属功能分支及 PR；同组前置依据该分支的提交与通过的验收推进，跨组前置等待功能合并。本票在所属功能合并且验收通过后关闭。

边界：依赖 P04 的目标选择；不依赖旧消息路由增强或外部资源功能。

覆盖父规格用户故事：48, 49, 91。对应测试组：T06。

通过真实 dsh 装配、会话与隔离 PostgreSQL 验证用户可见及持久结果；仅替换模型、外部网络和时钟等边界。依赖内部具体函数调用顺序的断言不作为验收。

## Acceptance criteria

- [ ] 普通输入走 queue，明确补充才 steer；显示排队/执行状态，不因新消息默认打断。
- [ ] 停止当前 turn 与清空待处理工作是不同操作，按真实 Controller 语义处理并回执。
- [ ] 记录用户取消原因；停止不自动撤销已完成外部动作，回执分别说明已完成与未继续部分。
- [ ] 同一 Session 来自 Web/飞书的输入仍由同一 Host 执行，飞书不广播无关宿主输出。
- [ ] 验证 step 边界补充、取消当前仍保留待处理项、全部停止的明确意图以及不同会话不互相中断。
