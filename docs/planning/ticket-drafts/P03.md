## What to build

主人发起普通对话，24PA 创建或恢复默认真实 Session，并从已提交结果回复飞书。

**功能 PR：** F01 · 飞书助理与随手记（同组：P01、P02、P03、P14）。本票沿用所属功能分支及 PR；同组前置依据该分支的提交与通过的验收推进，跨组前置等待功能合并。本票在所属功能合并且验收通过后关闭。

边界：需要 P02 的主人、固定身份、耐久入口和结果投递。

覆盖父规格用户故事：1, 5, 6, 88。对应测试组：T01, T07。

通过真实 dsh 装配、会话与隔离 PostgreSQL 验证用户可见及持久结果；仅替换模型、外部网络和时钟等边界。依赖内部具体函数调用顺序的断言不作为验收。

## Acceptance criteria

- [ ] 默认会话使用助理 preset，固定身份；必要歧义才询问，模型不获得通用 Shell 或任意安装能力。
- [ ] 先保存委托和目标，再通过 SessionController 准入并 flush，回执关联请求、消息与 turn。
- [ ] 仅从已提交的最终输出建立 Outbox，不把临时 token 或 accepted 状态当任务完成。
- [ ] 同会话准入串行并复用稳定请求标识，重复准入和入队后退出能对账；保留可供后续恢复使用的工作阶段。
- [ ] 用真实 Loader、Agent、Session 和 PG 验证多轮上下文与重启后的历史；仅替换模型和外部网络。
