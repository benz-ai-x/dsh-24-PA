## What to build

主人从飞书或本地24私助会话提出委托，助理理解、澄清并按实际入口回复；默认本地入口和飞书接入分别恢复原生会话。

**功能 PR：F01 · 工作区助理与随手记**。本组 5 张实施票共用一个功能分支及 PR，一个 PR 交付一个可用功能，不按单票建 PR。

同组前置在该功能分支已有提交且验收通过即可继续，前置票可保持打开；跨组代码依赖须等对应功能合并并通过验收。本票在所属功能合并且验收通过后关闭。

该功能合并前置：无。

**依赖理由：** 需要 P02 的真实入站、主人校验和耐久接收/发送；本票完成顶层 Lead，专业委派由首个备忘流程建立。

**覆盖规格：** 用户故事 1, 5, 6, 38, 87, 88, 101, 102, 111, 112, 117；测试组 T01, T04, T07, T17, T20。

**验证边界：** 使用真实 dsh Loader、原生 Session/Agent 与隔离 PostgreSQL；仅替换模型、外部网络和时钟。观察真实工具执行、持久状态及最终用户结果，不以模型自述或内部调用顺序代替验收。构建产物、权限、重复、部分失败、重启和必要迁移/恢复说明随本票交付；相关真实飞书/模型验证另记实测或未验证状态。

## Acceptance criteria

- [ ] 只提供一个对用户可见的24私助 preset，协调与维护共用；通过 SessionController 创建/恢复固定飞书接入和默认本地助理会话，本地可新建同预设会话。实际模型输入包含所选工作区 AGENTS.md。
- [ ] 飞书新消息统一送固定接入会话，本地委托进入实际原生顶层会话；均保留固定主人/profile，信息完整的本人指令不重复确认，影响执行的歧义才询问。
- [ ] 先耐久保存原输入与 WorkItem/准入目标，再提交 Session、flush 和保存 request/message/turn 回执；accepted 不表示任务完成。
- [ ] 仅从已提交最终结果建立带事项来源的交付记录，按 origin 与固定目标回传；本地结果不进飞书 Outbox。会话准入串行，重复事件及入队后退出可对账，已有完成结果不重做。
- [ ] 根据宿主核验的工作区、入口、实际父子关系和当前角色授予工具；同一 preset 不代表相同权限。本地维护工具由 P41 提供，飞书接入与 child 无维护写权限；全部不开放任意 Shell/安装，跨会话输出不自动发飞书。
- [ ] 通过同一24私助对话入口在本地和飞书完成多轮与恢复；旧会话若被改成其他 preset，保留历史并另建正确入口，不重写既有身份。产品更名不改变会话绑定。
