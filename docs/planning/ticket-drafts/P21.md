主人设置静默、休假和频率策略，服务恢复后只收到仍有用的通知。

**功能 PR：** F05 · 个人提醒与免打扰（同组：P15、P18、P20、P21）。本票沿用所属功能分支及 PR；同组前置依据该分支的提交与通过的验收推进，跨组前置等待功能合并。本票在所属功能合并且验收通过后关闭。

边界：P15 提供有效偏好，P20 提供周期发生实例供策略控制与验证。

覆盖父规格用户故事：55, 57, 58, 60。对应测试组：T09。

通过真实 dsh 装配、会话与隔离 PostgreSQL 验证用户可见及持久结果；仅替换模型、外部网络和时钟等边界。依赖内部具体函数调用顺序的断言不作为验收。

## Acceptance criteria

- [ ] 使用有效偏好处理安静时段、临时休假、合并和频率限制；明确预约提醒的覆盖行为在设置回执说明。
- [ ] 静默结束后按有用时段补发或合并，结束会议和过期简报不集中轰炸。
- [ ] 稍后实例与原发生实例关联，取消/完成后不会在静默队列再次发送。
- [ ] 平台限流按有界退避，权限错误进入重新授权；过期 lease 不可提交新 worker 的结果。
- [ ] 测试跨日静默、长时间停机、多来源通知、明确预约覆盖和到期后取消。
