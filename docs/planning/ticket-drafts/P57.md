## What to build

业务账本存储改为**默认 SQLite、可选 PostgreSQL**（交付五块）：

1. **存储适配层**：`storage: 'sqlite' | 'postgres'`（缺省 sqlite）配置面；方言翻译适配（`$n`/`any()`/cast/`now()`/`make_interval`/`ilike`/行锁剥离，残留 PG 方言即抛错）；DDL 与列类型回收从同一份迁移清单推导；禁止任何静默退回。
2. **驱动落地**：`node:sqlite` 内建（Node ≥ 23.4，不可用时显式报错）；WAL＋单写连接＋AsyncLocalStorage 事务归属。
3. **SQLite 运行面**：账本落工作区 `data/pa24.db`；备份＝checkpoint 后文件拷贝（PG 路径不变）。
4. **测试矩阵**：sqlite 单测（翻译/迁移/往返/事务）＋e2e `PA24_E2E_STORAGE=sqlite` 全量切换＋PG 默认回归。
5. **文档与规格同步**：SPEC 故事 95/非功能条款/T14/验收第 6 条反向修订＋故事 131、整体设计方案、初始化指南（PG 降为可选、Node ≥ 23.4）、README×4、#46 工单正文、索引/交付计划。

**功能 PR：F25 · 默认 SQLite 存储**。单票单 PR。

**覆盖规格：** 用户故事 131（＋修订故事 95）；测试组 T14 改双后端。

**验证边界：** 已部署 PG 实例（Ops-Space/aliyun）升级后须显式 `storage: "postgres"`（升级说明随发版）；`node:sqlite` 可行性已实证（本机 Node 26，SQLite 3.53.4）。
