## What to build

主人设置每天、每周、每月或指定日期提前提醒，并能跳过一次或停止以后。

**功能 PR：F05 · 个人提醒与免打扰**。本组 4 张实施票共用一个功能分支及 PR，一个 PR 交付一个可用功能，不按单票建 PR。

同组前置在该功能分支已有提交且验收通过即可继续，前置票可保持打开；跨组代码依赖须等对应功能合并并通过验收。本票在所属功能合并且验收通过后关闭。

该功能合并前置：F02 并行事项与记忆维护。

**依赖理由：** 建立在 P18 的一次发生实例和投递控制上。

**覆盖规格：** 用户故事 54；测试组 T09。

**验证边界：** 使用真实 dsh Loader、原生 Session/Agent 与隔离 PostgreSQL；仅替换模型、外部网络和时钟。观察真实工具执行、持久状态及最终用户结果，不以模型自述或内部调用顺序代替验收。构建产物、权限、重复、部分失败、重启和必要迁移/恢复说明随本票交付；相关真实飞书/模型验证另记实测或未验证状态。

## Acceptance criteria

- [ ] 复用 dsh 公开 every/daily/weekly/cron 规则及 recurrence 函数，校验其实际支持范围。
- [ ] 保存 UTC 发生点、IANA 时区与原表达，区分固定本地时间和固定间隔。
- [ ] 每个发生实例与 Outbox 在 PG 事务内唯一建立并推进规则；同一规则不同时交给原生 Agent Schedule 发送。
- [ ] 支持跳过本次、暂停和停止以后，重要日期保留用户提供的准确日期及提前量。
- [ ] 测试 DST/跨月等调用契约、最近错过实例及重启；不复制 dsh 自己的算法实现和全部算法测试。
