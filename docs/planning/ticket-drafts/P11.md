## What to build

主人明确安排或调整个人日程，看到变更范围、实际日程链接和结果。

**功能 PR：F04 · 日程与会议安排**。本组 3 张实施票共用一个功能分支及 PR，一个 PR 交付一个可用功能，不按单票建 PR。

同组前置在该功能分支已有提交且验收通过即可继续，前置票可保持打开；跨组代码依赖须等对应功能合并并通过验收。本票在所属功能合并且验收通过后关闭。

该功能合并前置：F03 任务与项目清单。

**依赖理由：** P10 提供日历对象与同步；P08 已建立首个实际外部写入及对账契约。

**覆盖规格：** 用户故事 23, 25, 53, 88, 89；测试组 T02, T05, T08。

**验证边界：** 使用真实 dsh Loader、原生 Session/Agent 与隔离 PostgreSQL；仅替换模型、外部网络和时钟。观察真实工具执行、持久状态及最终用户结果，不以模型自述或内部调用顺序代替验收。构建产物、权限、重复、部分失败、重启和必要迁移/恢复说明随本票交付；相关真实飞书/模型验证另记实测或未验证状态。

## Acceptance criteria

- [ ] 通过授权日历创建、改期和取消；利用已有任务查询展示关联任务、冲突和受影响安排；未授权时不更改关联任务或其他日程。
- [ ] 沿用备忘建立并经 P08 任务验证的外部操作/资源协调契约；日程版本或外部修改冲突需重新核对。
- [ ] 复用 P10 同步事实，写后回读并让其他会话使用最新对象状态。
- [ ] 创建或修改结果未知时查询/幂等核对，不能重复创建会议或占用。
- [ ] 验证时区、重复实例调整、取消与外部编辑竞争，并返回真实回执。
