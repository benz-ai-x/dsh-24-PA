## What to build

主人的 QwenNote（钉talk）录音卡听记（会议转写、纪要、速记，云端＝钉钉 AI听记 `minutes.qwennote.cn`）成为24私助可直接读取的资料来源。通道复用 dsh 内建 `@deepseek-ai/dsh-mcp-client`（profile `cordis.patch.yml` 条目，stdio＋`mcp-remote` OAuth 桥，`serverName: qwennote`），24PA 不自研 MCP 客户端、不新增包依赖；行动提炼走既有候选行动→审核→行动授权流程。研究依据：[F18 研究](../../research/F18-QwenNote听记MCP接入研究.md)。

交付分三层：

1. **通道（部署配置＋指南）**：初始化指南新增「听记接入」节——patch 条目（mcp-remote 锁版本）、首次授权由本人浏览器完成（对齐飞书接入向导口径）、诊断三态（未配置/未授权或过期/正常）。
2. **放行（插件）**：`extraLocalTools` 语义扩展至 `mcp__qwennote__*`（GLOSSARY 词条同步改写），仅 local-robot 角色；extras 并入 allow 前按已注册工具做存在性过滤，消除「配置点名但通道未装 → restrict() 抛错」路径。
3. **教学（插件）**：`src/prompts.ts` 业务域节补「听记资料」规则（何时查询、来源标注、行动走既有确认流程），快照测试同步。

**功能 PR：F18 · QwenNote 听记接入**。单票单 PR。

**覆盖规格：** 用户故事 125；测试组随规格 1.7 同步落版时定（提示词快照＋放行路径单测为本票必测项）。

**验证边界：** dsh-mcp-client 契约以 0.2.0-rc.2 / 0.2.1-alpha.1 源码为准（已核，见研究三）；QwenNote MCP 的 OAuth 形态、工具面、配额、token 续期**未经授权实测**——本票第一步为真机打通（授权由本人浏览器完成）并把结论回填 F18 研究文档；若 mcp-remote 不兼容且无静态 token 通道，架构回提案重审。

## Acceptance criteria

- [ ] 真机完成 OAuth 授权打通；`tools/list` 工具盘点（清单、参数语义、只读/写、配额、token 寿命）回填 F18 研究文档。

- [ ] profile 未配 mcp-client、token 失效或未授权时：会话不崩溃，诊断给出对应三态与 nextSteps。
- [ ] 飞书入口会话与 Worker 不出现 `mcp__qwennote__*` 工具；extraLocalTools 点名不存在工具时被过滤并有可观测提示。

- [ ] 初始化指南「听记接入」节可让新实例从零完成接入与首次授权。
- [ ] 文档同步：SPEC 1.7（故事 125）、GLOSSARY（听记词条＋extraLocalTools 改写）、工单索引与 PR 交付计划。
