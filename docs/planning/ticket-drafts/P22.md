## What to build

主人建立周期事项，系统按发生实例生成真实飞书任务，支持跳过单次或停止后续。

**功能 PR：F08 · 事项交办与持续跟进**。本组 4 张实施票共用一个功能分支及 PR，一个 PR 交付一个可用功能，不按单票建 PR。

同组前置在该功能分支已有提交且验收通过即可继续，前置票可保持打开；跨组代码依赖须等对应功能合并并通过验收。本票在所属功能合并且验收通过后关闭。

该功能合并前置：F04 日程与会议安排、F05 个人提醒与免打扰。

**依赖理由：** P09 提供任务维护，P20 提供已验证的周期实例与跳过语义。

**覆盖规格：** 用户故事 17；测试组 T02, T09。

**验证边界：** 使用真实 dsh Loader、原生 Session/Agent 与隔离 PostgreSQL；仅替换模型、外部网络和时钟。观察真实工具执行、持久状态及最终用户结果，不以模型自述或内部调用顺序代替验收。构建产物、权限、重复、部分失败、重启和必要迁移/恢复说明随本票交付；相关真实飞书/模型验证另记实测或未验证状态。

## Acceptance criteria

- [ ] 优先复用飞书满足需求的重复能力；需要模板时使用 dsh 时间规则与 PG 唯一实例。
- [ ] 每个实例生成一次真实任务并链接来源模板，不重复建影子任务库。
- [ ] 区分完成本次、跳过本次、修改以后与停止以后；已完成历史保留。
- [ ] 生成成功但响应丢失先核对操作回执，暂停期间不无界补建旧实例。
- [ ] 演示每月检查事项跨两个实例、重启和规则变更；不因两个会话同时访问而重复生成。
