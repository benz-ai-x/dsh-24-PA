## Parent

[规格 #1 · 24私助（24PA）v1.6：统一助理、工作区与手写审核](https://github.com/benz-ai-x/dsh-24-PA/issues/1)

本票来自用户 2026-10-07 人工体验反馈「UIUX 总有那么点不舒适」：六屏视觉走查（宿主首页/事项总览/飞书接入/企微接入/结构化记忆/设置分区）定位三个系统性根因——首屏垂直预算失衡、徽章/按钮/栅格组件制度不统一、文案对机器友好对人不够。纯视觉与文案打磨，不升规格（色值与密度为视觉实现选择，SPEC §13 既有契约内执行）。

## What to build

1. **垂直预算**：header 压缩（标题 29px→21px、口号并入标题行、品牌块缩小）；卡片 padding 22px→16px、fields 行距与 section-head 间距收紧；设置分区根节点补 `min-width:0` 修复横向溢出裁切。
2. **组件制度**：状态徽章统一四档语法——通用状态词（正常/待核验/需要处理/待配置/尚未检查）各配固定 tone 与图标（check/clock/alert/info），全部状态徽章（就绪项、健康能力、飞书诊断、企微服务授权）共享同一 `STATUS` 映射；诊断徽章可保留具体原因词（未授权/已过期/企业不可用/未启用）但 tone/图标必须取自同档（SPEC §13「状态全局一致」）；「长连接已启动/未启动」为 SPEC §13 第 381 行锚定术语保留。名称徽章（企微/飞书）改中性底＋渠道图标；一屏一主按钮（检查类只读动作降为描边，「绑定所选工作区」升为卡内实心，设置分区外跳 CTA 降为 quiet，健康读取去实心）；双列 grid `align-items:start` 让短卡收缩；长机器值（userid/openId/路径）省略号＋title。
3. **文案分层**：默认人话（「数据保存在本机数据库」「待发消息 N 条」去掉 Outbox 术语），技术细节留页脚/折叠；体验模式黄条可关闭（飞书接入页「接入模式」字段为常驻标识，关闭黄条不违反 SPEC §13「体验模式明确标识」）；PostgreSQL 提示三处去重；企微 helper 隐藏内部参数（action=wecom_guide）改为对话式指引；密度同批收紧含统计卡字号/边距与网格间距。
4. **语义配色**：tab 按设计方案视觉段（`docs/24PA-整体设计方案.md`：「蓝绿主操作、蓝色日程、紫色记忆/备忘、琥珀提醒/审核及玫红手写/异常」）对齐——事项总览蓝、接入页蓝绿、记忆紫、手写审核玫红（复用 danger）；补 tone-green/tone-violet 两个语义色（明暗主题）；侧栏图标补 title 悬停提示（无障碍名由宿主 register 的 label 提供）。
