## What to build

1. **卡片**：CARD_REGISTRY 注册 `config` 卡（cat: system）：body 摘要（模式/三渠道/存储三行＋configError 告警）、tier（configError→warn）、detail＝参数表单。
2. **表单六组 22 项**（已审清单）：
   - 模式与身份：mode（下拉）、larkProfile（文本）、ownerOpenId（**只读＋「从当前授权复制」**——取飞书诊断 openId，未检查时提示先跑检查；决策点 A 采纳）、timeZone（下拉＋自定义）
   - 渠道选择：calendarChannel/todoChannel/notifyChannel（下拉 feishu/wecom）
   - 飞书资源：folderToken/tasklistId/calendarId（文本＋粘贴链接自动提取 token；wikiNodeToken 位随 F22 落地补入）
   - 运行参数：maxWorkers（1–8 步进）、enabledWorkers（多选）、workerModels（按角色子表单 provider/model/simplePersona；handwriting 未配路由显式提示）、extraLocalTools（折叠区多选）
   - 存储与密钥引用：storage（**只读显示＋迁移指引**——决策点 B 采纳，切换涉及数据迁移非纯参数）、appIdEnv/appSecretEnv（只读引用名）、pgDsnEnv（sqlite 时禁用）
   - 语音 TTS：tts.engine（下拉 none/melo/volcengine）、tts.voice（音色＋**试听**＝复用 F19 `tts.test`）、tts.volcKeyEnv（引用名）、tts.meloDir（melo 时显示）

4. **i18n**：全部新文案走 F27 L() 双语通道。
5. **规格修订**：§13 表单条款收窄＋故事 132；README 四件提一句表单入口（随 PR）。

## Acceptance criteria

- [ ] 主面板「系统维护」出现「参数配置」卡；点开二级详情见六组 22 项，当前值来自 snapshot.config。
