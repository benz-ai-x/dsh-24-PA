# 24私助（24PA）v1 工单清单（规格 1.2）

更新：2026-10-05。依据 [规格 #1](https://github.com/benz-ai-x/dsh-24-PA/issues/1) 全文及评论、整体设计 v0.4、已确认 Q1–Q6 和最新原型设计。44 张工单已在上一轮发布，本轮根据用户要求同步命名、单一预设与界面验收。

共 **44 张工单**：43 张实施票归入 **12 个功能 PR**，P40 是整体发布验收，不预设独立 PR。当前已发布 44/44 张。工单发布不等于启动正式开发或生产部署。

既有 P01–P44 保留规划编号并校准到规格 1.2；其中 P41 负责配置维护与接入查阅，P42 负责 JSON 条目维护与内容展示，P43 负责手工整理与撤销，P44 负责 Worker 扩展。每票交付完整可验证流程，持久化、授权和恢复随首个业务流程一起建立。原型仅供参考，无必须先做的大范围重构。

P 编号为稳定规划编号，GitHub 编号为实际事项；以下按依赖顺序排列。各票仅列直接阻塞边，传递依赖已去除。同组提交与验收可推进后续票，跨组依赖按功能 PR 合并判定，详见 [PR 交付计划](24PA-v1-PR交付计划.md)。

本清单覆盖 118 条故事、S01–S30 与 T01–T20；覆盖映射在后文。父规格 #1 同步为1.2，状态/标签和既有依赖保持；UI/UX 验收归入原功能，未新增第13个 PR。
