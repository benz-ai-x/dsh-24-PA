## 跨模块与回归证据

自动化装配使用真实 dsh Loader、Session provider、SQLite 或隔离 PostgreSQL；模型和外部平台进程使用测试替身。宿主固定 `1600d8a1e140dcde43a1a0941940a0480712c011`，Node `v26.4.0`。结果只证明这些明确边界，不证明真实账号权限和设备提醒。

| 验收组 | 覆盖方式 |
|---|---|
| Skill → 计划 → 待办 → 运行与投递 | 原生调度；固定版本/来源/身份；重复触发和重启；创建修改完成取消；结果与投递分别留证 |
| 等待、停止、重试与人工接续 | 缺权限或参数前无平台写入；补充沿原运行；未知结果先核对；预算许可只解除预算阻断 |
| 审核 → 候选行动 → 平台对象 | 版本与主体核验；逐项授权；源变更失效；成功不重复；直接资料动作进入运行档案 |
| 记忆 → 联合备份 → 隔离恢复 | 新旧记忆合并；永久删除；审计/修订损坏；必需表、列和笔记序号；原稿、裁片、版本与 Session 附件 |
| 接入、预算与恢复 | 健康证据和身份版本；计划和旧待发；预算等待与已用/未用许可；隔离标记阻断正常绑定 |
