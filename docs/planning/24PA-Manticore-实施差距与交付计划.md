## 2026-10-20 初始实施门槛（历史盘点）

1. **M01a 已满足研究门槛**：内置原件可直接读取；registry snapshot 仅观察获胜项，complete 不等于全部文件有效；每个详情读取一次完整定义，选择含来源，导出校验内容指纹。管理查询与执行准入分离，所有读取无业务副作用。
2. **M01b 尚需验证**：真实文件 provider 的发布后刷新、同名处理、不可变包版本与故障恢复；ZIP 校验和安全发布不能用简单写文件替代。
3. **M02/M08 尚需验证**：统一运行身份、等待计时、停止及重启、跨运行未知对账；宿主 pre-step 拒绝会消费输入，预算控制须先保存可恢复上下文。
4. **M03/M04 尚需验证**：企微同版 schema 与文档的身份／查询范围冲突、多日历容器与负责人语义；飞书参与关系须另取可靠证据，不能从 agenda 缺字段推断没有参与。功能不足须报差异，不静默缩减需求。
5. **已有修复依赖**：#208 的原渠道／身份／容器／回执恢复供多来源写入复用；#209 的正文与候选同源供资料候选执行复用，不阻断直接对话与只读查询。两票已由原负责分支通过 #223/#224 合并、关闭，本分支已同步主线 `8938318`；后续 M03/M05 仍须执行各自交叉场景，不重复实现修复。

本节保留最初研究门槛，不代表当前仍未实现；各组交付与待验事项见[交付验收](24PA-Manticore-交付验收.md)。
