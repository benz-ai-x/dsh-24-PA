# 第三轮逐项复核证据

基线 `8f70020a2f3808c3afb899e88092ee430d222efd`，2026-10-19。

`reviewed-findings.json` 是复核定稿；`manifest.json` 保存原始输出文件、来源位置、大小与SHA-256；`baseline-validation.json` 记录现状测试通过情况。其余文件是隔离探针输出、实装CLI契约或测试日志，原样归档，因此早期输出中的推断必须结合逐项复核的更正阅读。

没有真实账号业务写入或部署。真实Runtime/SQLite/React/进程/已安装宿主代码只证明对应层行为；模型、Host部分及外部平台在多数探针中仍为可控adapter。源码可达性与动态实测的区别见每项结论。

这些输出不是新增生产测试，也不宣称所有临时探针均可在此目录直接运行。正式修复应将所列验收写入现有公开interface的回归测试；复核文档提供固定提交源码锚点，原临时脚本路径作为取证来源保留在原始JSON中。
