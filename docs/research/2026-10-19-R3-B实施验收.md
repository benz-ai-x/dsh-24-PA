## 已实现行为

- CLI 进程按字节限制输出，超时/超限后 TERM→KILL 有界回收，外部写入仍为 unknown。诊断版本检查与 pg_dump 复用该执行约束，备份上限见契约研究。
- 真实模式备忘通过 CLI 创建并回读，不再把机器人连接是否可用当成演示开关。旧无文档 demo 成功只在本人重试同一保存请求时修复；已有文档与 unknown 不重放。
- 平台消息键包含渠道、类型、完整业务键和目标的稳定摘要；SDK text/card 与 CLI audio 均保留实际业务身份。
- 飞书/企微按对象 ID 观察，完整更新标题、截止与终态；坏数据或权限失败保留 stale。每任务 gate 保持观察与写入顺序；本地计划/估时保留。
- 企微完成只请求本人份额，逐项回执必须匹配 todo_id 且 success=true；整项状态另行读回。个人份额完成仍 open/partial；无有效回执 unknown，不自动扩大 finished_all 权限。
- 企微日期型截止直接传原日期，时刻型按工作区时区；显式身份检查刷新缓存，并发共用检查，失败不沿用旧身份，持久通知目标不变。
- 项目 next、晨报负荷、次日规划仅包含 open；任务来源核验先查权威状态，完成/取消失效，读取失败 unknown。
