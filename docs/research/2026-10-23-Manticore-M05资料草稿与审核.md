# Manticore M05：资料草稿与版本审核

基线：24PA `51b5603`；dsh `1600d8a1e140dcde43a1a0941940a0480712c011`（0.2.1-rc.1）；Node 26.4。规范：已审核 Manticore 定稿「手写审核与行动授权」「听记与知识库」、SPEC §9–10/13、#218。

## 可复用契约与核验

- 现有 HandwritingPipeline / NoteRepo / TrustedNotes 已覆盖按版本冻结、原稿资源回读、七日不透明令牌、主体校验、事务裁决、投递去重与失败后恢复。沿用 #208/#209 修复，不另建审核状态机。
- `note-derivation.ts` 用正文与派生内容双摘要证明同源；编辑远端文档后重新发布不得携带旧候选。本轮继续执行此限制。
- dsh `packages/core/session/src/types.ts` 的 `tool/call`（name/callId/arguments）与 `tool/result`（message.toolCallId/isError/content）提供实际调用依据。MCP `packages/mcp/mcp-client/src/tools.ts:call` 将 upstream isError 映射成失败；工具挂载与 token 缓存不能证明读取资料成功。只观察已获准本地会话的真实结果，不在刷新中调用 MCP。
- QwenNote 工具名及参数仍以运行时挂载 schema 为准；复用 F18 研究和原有本地通道，不新增客户端或尝试新的授权。资料仅在主人选取后保存为审核草稿；不全库同步、不落默认记忆。
- 外部行动依赖已合并 M03 与 M04 的 taskCreate/calendarWrite 入口；参数使用 sourceId/company/project、assigneeIds 与稳定 operationId。M04 未合并前其新增范围不宣称交付。

## 实施取舍

1. `note_material` 仅保存单篇已选资料的可编辑草稿、识别结果、来源、单调 revision 与发布关联；冻结审核版本仍在 note_version。原始图像路径不向浏览器开放，单页读取验证路径归属与摘要。
2. 保存草稿不调用飞书或模型；显式发布从冻结草稿建立新版本，发送审核卡。重新识别结果单独保存，存在人工修订时不覆盖草稿。历史读取只用本地快照。
3. 候选行动具有 note 范围稳定 ID；匹配依靠明确 ID 或唯一相同字段，含糊项分配新 ID。授权绑定版本及最终参数，成功对象跨版本只显示关联或变化建议；未知结果保持阻断。排序不触发复制对象。
4. 听记来源保留真实资料类型、标题、资源引用和实际读取凭证；没有图像原稿时不伪造页。审核发布仍需真实飞书配置，本地面板无批准按钮。
5. 迁移暂预留 29，供总集成排序；单树隔离验证不得把跳号测试库拿去升级另一开发树。
