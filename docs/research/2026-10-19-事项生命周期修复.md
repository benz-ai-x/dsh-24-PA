# 事项生命周期修复研究

2026-10-19；产品基线 SPEC 2.12 §5–8/§12，ADR-0001，F02/F12/F25 既有研究。

## 来源、取舍与验证

- WorkItem 探针：maxWorkers=1 时首项 turn/end 后第二项仍 queued；continue 发送失败仍 running。pump 的 count/list/update 未串行，follow-up 也绕过容量检查。现有测试未触达这些行为。

- WorkItemLifecycle 集中单 Host 准入串行、排队认领、继续/停止/回合终结和失败回滚，使用真实 repository 与原生 child adapter。宿主已有单实例锁，未引入多主调度器。补 FIFO、空闲槽回填和重启排队行为测试；继续保持原 parent/child 身份。

验证：WorkItemLifecycle公开interface SQLite/PostgreSQL共12项通过；真实Loader F02双后端各5项通过。结果状态与local/feishu Outbox同事务提交，消息固定原入口且带turn身份；本地原生prompt/flush失败不吞错误。
