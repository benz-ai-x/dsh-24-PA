日期：2026-10-07。结论在实现前调研、实现中验证；本文补记研究来源与取舍（code-review 提出，见 PR #61）。

## 已验证的关键契约

1. **各标准插件注册的工具名**（逐一 grep 各包源码）：tool-fs→`read/write/edit/read_image`；fs-search→`glob/grep`；bash/pwsh 平台互斥；tool-jobs→`job_kill/job_list/job_output`；skill→`skill`；goal→`create_goal/get_goal/update_goal`；plan-mode→`exit_plan_mode`；ask-user→`ask_user_question`；todo→`todo_write`；web→`web_fetch/web_search`；present→`present`；subagent 实例按 `toolName`（`subagent/subagent_fork/subagent_codex/subagent_claude_code`）；subagent-control→`interrupt_agent/send_message`＋`list_agents`；tool-workflow 默认 `workflow`；ralph→`ralph`。
2. **restrict() 语义**：allow/deny 名单中每个名字必须是该 agent scope 链上的**现存**工具，否则抛错（index.ts:1117）。`get(name)` 不带 scope 只看全局层——预设把工具注册在 agent 平面（祖先层），因此**不能**用 get 做运行时探测（实测返回全空）。结论：白名单只能列「必然注册」的工具；平台 shell 二选一在代码里按 `process.platform` 写死。
3. **toolFilter 契约**：`dsh-tool-subagent` 的 `toolFilter` 引用不存在的工具名会**启动失败**（"unknown names fail startup"）。因 C-4 去掉 tool-schedule，标准预设 subagent 行的 `deny: schedule_*` 必须一并移除（e2e 首轮失败实证）。
4. **modelSelectionSettings 契约**：要求宿主面存在 `@deepseek-ai/dsh-tool-subagent/model-selection-settings` 服务（index.ts:611-617）。目标部署不保证该行存在，故 pa24 预设的 spawn 行去掉该开关；代价是子 Agent 模型选择设置面板不生效，工具本身可用（e2e 实证 `subagent` 正常注册）。
5. **codex/claude-code provider 可用性**：`subagent-codex`/`subagent-claude-code` 包**不在** web-app bundle 依赖内（其 README：安装 provider 是 profile 级部署决策）；工具行引用的 provider 未注册时工具不挂载、不报错。因此采用「预设行启用＋`extraLocalTools` 配置显式开启」两层设计——restrict() 的实名约束使默认开启不可行。
6. **预设/宿主分层**：web profile 把标准工具行的宿主面副本禁用，预设行按 agent 组合生效（`bundle/web-app/cordis.patch.yml` 注释）；pa24 patch 插入自己的预设行互不冲突。

## 取舍记录

- **time-context 保留**：在 0.2.1-alpha.1 基线的 standard.patch.yml 中存在（rc.2 主 checkout 的同名文件没有——审查曾据此误判为范围蔓延）；属「标准全集」的一部分，所有预设会话（含飞书/Worker）获得时间上下文，对提醒时区语义有益，未改变工具面。
- **tool-schedule 不并入（C-4）**：提醒保持 PG 账本单轨（离线可发、Outbox 回执）；原生 schedule 工具会形成第二套提醒语义。
- **bash/pwsh 选择在 yml 与 ts 两处重复**：预设行 `disabled: !!js process.platform…` 与 `STANDARD_CODING_TOOLS` 的三元各写一次（YAML/TS 无法共享常量）；已知耦合，改动 shell 集时需同步两处并在 e2e 平台断言兜底。
- **本地/飞书/Worker 三面断言**：飞书与 Worker 采用封闭集合严格相等（`slice().sort()` 相等），本地因平台 shell 与 provider 可选性采用 arrayContaining＋缺席断言。
