# 预设继承机制上游提案研究（P3）

状态：本地缓解已落地（PR #91）；**向上游 deepseek-harness 提案待用户授权**，本文为提案底稿。调查日期：2026-10-11。

## 问题：「标准预设＋delta」在 dsh 0.2.1-alpha.2 上无法表达

24私助预设（F13 裁决，规格 1.3）＝ dsh 标准预设全集＋少量 delta，但底座三层机制均不支持继承，只能整份拷贝 standard.patch.yml：

| 层 | 证据（dsh 0.2.1-alpha.2 源码） | 结论 |
|---|---|---|
| loader patch 合并 | `vendor/include/src/index.ts` `applyEntryPatches`：按 id 找到目标行后 `target[key] = value` 逐键浅覆盖 | `config` 整体替换，`config.plugins` 数组不按元素合并 |
| loader insert | 同文件 `insert` 分支：无 id 追加根列表；带 id 仅追加进 loader 层 **group** 条目 | 够不到 agent-preset 行 `config.plugins` 内部 |
| 预设定义 | `packages/preset/agent-preset-registry/src/definition.ts` `PresetDefinition`：仅 `id/name/description/order/plugins` | 无 extends/继承字段 |

拷贝同步的实测成本：

- 0.2.1-alpha.2 一次手工同步即含 plan-mode 措辞、persona cwd 后缀、subagent backgroundMode 等隐蔽变更，靠人工 re-diff 捕获（旧 cordis.patch.yml 头注释为证）；
- 本地 harness checkout（d743267388）与 npm 发布 tarball 在 plan-mode 一行措辞上不一致，手工拷贝跟的是 checkout 而非消费者实际安装的 tarball（PR #91 生成器首次运行即捕获）。

## 本地缓解（已交付）

`packages/24pa/scripts/sync-preset.mjs`（PR #91 / Issue #90）：从 devDependency 钉住的 `@deepseek-ai/dsh-web-app` tarball 读 `presets/standard.patch.yml`，AST 级应用声明式 delta 生成 `cordis.patch.yml`；`--check`＋单测逐字节防漂移；锚点缺失/语义变化显式失败。漂移风险消除，但拷贝本身与「每个 bundle 作者都要自造同步工具」的成本仍在——根治需底座支持。

## 提案方向

### 方案 A（推荐）：registry 层 `extends`

`PresetDefinition` 增加 `extends?: string | string[]`（按 id 引用已注册预设）；registry 解析时合并 plugins：

- 同 id 行＝子覆盖父（config 深合并可选，先做整行替换更简单）；
- 新 id 行＝追加（或支持 `before/after` 锚点控制位置）；
- 需处理：循环引用检测、父预设未注册的报错语义、`composition-inventory` 工具面展示继承来源。

优点：合并发生在有领域语义的 preset 域；loader 保持通用；`order` 等元字段继承规则可一并定义。风险：注册时机依赖（父预设包需先可用——与现有 provider bundle 的惰性挂载模式一致）。

### 方案 B：loader patch 层按 id 深合并 plugins 数组

`PatchOptions` 对 `config.plugins` 支持 opt-in 的按 id 合并（如 `merge: ['config.plugins']` 声明合并路径）。

优点：不动 preset schema，所有组合面（含非 preset 行）受益。风险：通用「数组按 id 合并」语义模糊（id 键名约定、顺序语义），loader 层做出领域假设容易失控。

**推荐 A**：与 cordis 组合模型正交，语义闭环在 preset registry；B 可作为远期通用化。

### 对 24PA 的收益

`cordis.patch.yml` 从 ~160 行缩为 ~30 行：一行 `extends: standard` ＋ persona 前缀覆盖 ＋ 删 tool-schedule（及其 toolFilter/modelSelectionSettings 残留）＋ 加 ralph/codex/claude-code/pa24-agent ＋ 宿主行；基线升级零 diff 评审（上游变更自动继承）。
