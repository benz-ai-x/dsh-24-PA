## 可复用契约

复用已核验的 [渠道契约](2026-10-19-R3-B渠道契约.md)（lark-cli 1.0.87、wecom-cli 1.3.4 f9b2815）和 [知识版本与行动契约](2026-10-19-R3-C知识版本与行动契约.md)。当前生产 adapter 的四种回执并不相同：飞书任务保存 CLI data.task.guid，企微待办的已保存外部结果是解码后的 todo_id 字符串；飞书日程是 data.event.event_id，企微日程是 data.schedule_id。不能跨 adapter 复用未经核验的泛型结果。

ActionOperation 已持久化原 action、参数、work_item_id、授权及 _externalResult；可直接用这些字段固定恢复身份，无需 schema 迁移或新增操作执行器。已确认远端结果只补本地投影；running/unknown 且无回执仍需核对，不重发。

## 决策

- ExternalOperations 收拢候选创建记录的身份核验与恢复参数：有限四种 action，明确原渠道、容器、授权范围和回执格式；当前配置仅决定首次创建。缺字段、错 action/来源或未知格式的历史记录待核对。
- Runtime 调用原渠道 adapter；飞书任务接收已冻结的原清单。任务投影仍关联首次创建的 WorkItem。adapter 验证回执 ID 类型后才能保存投影；不能把飞书回执对象当作企微 todo_id。
- 同一候选继续使用原稳定键。笔记澄清不可变规则保留，重试指令不覆盖原授权；纪要和笔记各自保留当前领域流程，不新建泛化行动框架。
- 同 ID 异 action 必须在外部调用前拒绝；并发首次创建通过原持久 claim 和候选 gate 保护。
