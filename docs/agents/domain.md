# Domain Docs

本项目采用 **single-context** 布局：

- `GLOSSARY.md`：根目录的领域术语表。
- `docs/adr/`：项目级架构决策记录。

## 探索前读取

探索代码或领域设计前，读取根目录 `GLOSSARY.md`，以及 `docs/adr/` 中与当前工作有关的 ADR。

这些文件尚不存在时，直接继续；不用把缺失列为问题，也不用预先创建空文件。术语或决策实际确定后，由 `domain-modeling` 按需维护。

## 使用统一术语

Issue 标题、设计提案、假设和测试名称中的领域概念，采用术语表定义的名称。需要的概念尚未收录时，先判断是否确有新概念；确有缺口时留给 `domain-modeling` 补充。

## 处理决策冲突

方案与现有 ADR 冲突时，明确指出 ADR 编号、冲突内容和重新讨论的理由，再处理该决策；不能静默覆盖。
