# Triage Labels

工程技能使用以下五个角色；GitHub 标签名保持默认值。

| 技能角色 | GitHub 标签 | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格明确，可交给 Agent 实施 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不予处理 |

技能提及某个角色时，使用第二列标签。后续更名只更新第二列，保持角色名称不变。
