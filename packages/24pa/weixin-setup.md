# 微信 ClawBot 接入

本功能随24私助提供，使用自研 iLink 传输。无需安装 dsh-im 或 OpenClaw。微信接入要求 dsh `0.2.2-rc.1` 的公开会话接口；已有飞书主人、工作区和日历／待办来源保持原配置。

1. 在电脑端打开 **24私助工作区 → 接入与设置 → 微信 ClawBot**，点击「扫码绑定微信」。
2. 用本人微信扫码并在微信确认。电脑端显示候选账号和本人身份；先预览，再勾选身份与影响确认，点击「确认应用」。扫码成功本身还未启用收信。
3. 从微信发 `/24pa`，核对帮助回复。页面分别显示最近收信与发送接纳记录；平台接纳不代表已读。
4. 可以文字交办日程、待办、备忘，查询交办进度，按明确事项编号补充、停止、继续。日历／待办仍由原授权来源承接，微信不会扩大其权限。
5. 晨报、晚间复盘、周回顾和一次性常用计划交给 reminders Worker 管理。新增、改时、恢复和语音选择须先看预览，再回复给出的确认文字。新晨报默认智能规划；明确选择固定模板则使用模板。面板和微信管理同一原计划，通知目标和历史保留。

微信首版只收发私聊文字。图片、文件、语音、审核、配置、本地 Skill 和完整运行记录请在电脑端处理。周期结果的微信通知未开放；原计划语音仍按其已有渠道能力执行。微信原生引用尚未作为可靠路由启用，续办时给出明确事项编号。

## 停止、续期和换绑

- 「停止微信入口」阻止新收信、派发及发送；在途工作可以保存原结果，待发仍指向原身份。
- 原账号和主人身份相同的重新登录保留会话、绑定代次和收信位置。扫码可能改变微信平台侧授权，取消候选不承诺平台旧授权继续有效。
- 换身份或解绑前查看影响预览，处理原绑定未结输入、工作与投递。其他渠道的无关记录不会阻止微信换绑。已退休会话始终保留远程身份，不能取得本地工具权限。

## 结果未知与恢复

在「原绑定记录与核对」查看原内容、收件人、输入与交办编号。发送未知不自动重发；本人确认已收到只补记。核对未收到后可以明确补投原内容，有重复风险；业务不会重跑。明确未发送的消息可放弃；分段逐条核对，前段未知时后段不会先发送。

已接纳输入重启后按原宿主持久记录恢复，不重发到模型。仍排队或已消费但未完成的输入保留待核对。可以打开原会话处理；停止入口后、原会话不运行且没有该排队输入时，可填写依据关闭原输入。关闭不证明业务成功，也不撤销已发生的动作。

凭据和回复上下文只保存在工作区专用凭据库，目录权限 0700、文件权限 0600；不进入业务账本、模型或普通备份。联合备份包含微信会话、绑定、收信、游标、投递与核对记录。恢复副本保持隔离，重新扫码并核对原身份后才能接通，不盲目重投旧消息。

## 版本与验收边界

固定协议参照 Tencent/openclaw-weixin `2.4.10`。2026-11-08 本人账号隔离实验验证了即时回送及相隔约 6 分 31 秒、重启后复用原上下文回送；没有验证任意时刻主动发送、固定窗口、配额或服务端幂等。实际支持以本版本的验收记录与当前账号状态为准。
