# 微信协议隔离探针

用于 #279 的 WX-R01。它是一次账号实验工具，不是已完成的 F53/F54 接入，不会加载24私助业务、宿主会话、工作区配置或已有机器人凭据。

固定协议来源：Tencent/openclaw-weixin `874637a` / `2.4.10`。契约和仍未知的服务端条件见[协议核验报告](../../docs/research/2026-11-08-weixin-protocol-contract-verification.md)。使用 Node.js 22.19+；探针依赖单独锁定，不进入24私助发布包。

## 启动

在本目录运行：

```sh
npm ci --ignore-scripts
npm test
npm start
```

打开终端输出的本机地址。页面和凭据均只在本机；默认创建权限为 `0700` 的临时目录，状态文件为 `0600`。本地页面链接包含本次访问标识，不应分享。浏览页面不申请二维码；点击连接才访问腾讯服务。网络需要系统环境代理且 Node 支持时，可使用 `NODE_USE_ENV_PROXY=1 npm start`。

仅用本人明确用于测试的账号。页面说明测试范围和可能替换已有平台连接的影响；扫码后需本人核对候选身份并启用。随后向机器人发送页面上的唯一测试口令，探针只回两条标明测试编号的固定文本。没有真实扫码主人身份、可靠消息号或回复上下文时不发送。无关正文不入账，也不会被交给模型。

## 核验步骤

1. 扫码，必要验证码在本地页面输入，确认本人账号并启用。
2. 向机器人发送测试口令，核对即时回复。
3. 即时回复后探针会暂停，点“停止并重新读取测试记录”，再确认启用。这会重新构造探针并从磁盘加载游标、上下文和已发记录；记录为组件恢复，不冒充进程重启。
4. 不发新消息，等到距首次入站至少 120 秒后的一次延迟回复。长轮询可能使实际间隔略长，记录实际值。
5. 在本人微信里看到各条测试编号后，分别点“已收到”。接口响应与人工可见证据分别记录；助手不得代替本人点可见确认。
6. 停止测试并下载脱敏记录。审阅协议/身份/游标/响应形态、实测间隔、期间有无新入站，再判定 A。页面“本次证据已齐”不是正式微信集成验收；B 保持未验证。

如需真实进程重启，先停止服务，再使用终端原先打印的临时目录：

```sh
node server.mjs --state-dir /private/tmp/your-private-probe-directory
```

重启后使用新页面链接，默认停止，不自动收发。不要创建第二消费者。每个实验目录固定一个账号和两次出站；不导入既有账号、不换绑、不清除未知结果来补发。需要另一轮真实发送时须明确新的测试范围。

## 记录与边界

- `credentials.json` 独立保存 bot/context 凭据，不进入清洁账本、页面状态和导出。
- `ledger.json` 一次耐久写入本批清洁接纳/拒绝记录及对应游标，原生 ID 按字符串保留。导出仅保留其摘要及形状；不导出账号原值、游标、任意正文、二维码或验证码。
- 每条出站派发前固定客户端 ID，返回后先写独立 `receipts/` 观察记录再结算账本。恢复时只补账；已派发但无回执的请求归 unknown，不重发。
- 严格区分明确 `ret:0` 的平台接纳、非零业务拒绝及未知；原生消息号可选，客户端 ID 不冒充平台号。缺 ret、非预期 HTTP、截断与派发后超时不推断成功。
- 非零码、未知响应形状或没有即时接纳依据会阻止后续发送。本人对同一请求明确确认可见后，可从磁盘恢复并继续唯一的延迟测试；原 unknown 和响应格式保留，核对不生成 ret 或原生号。不要重复口令来补发。
- 短文本成功不证明长文限制、平台幂等、无限游标历史、任意延迟或主动通知。`notifystart/notifystop`、typing 和媒体在本探针中未调用，是否可省略由实测记录判定。
- 22 项离线与本地服务测试覆盖身份、无损 ID、回执、凭据隔离、去重、超时、停用迟到回执、崩溃恢复；它们不属于真实账号证据。UI 为开发实验页，不代替正式产品的双语 T20。

测试结束后正常停止服务；临时凭据仍留本机供本次核验续接。删除临时目录并不撤销微信平台授权；平台解绑需由本人另行处理。不要提交或上传整个临时目录。

2026-11-08 首次真实读取观察到 HTTP 200 的 `{msgs:[],get_updates_buf:string,sync_buf:string}`，省略 ret/errcode。读取判据因此独立校验已观察信封及无错误码，不再借用发送回执判断。此观察只证明读取响应形态；空发送响应仍为 unknown，账号收发结论仍待完整实测。

服务器真实即时回复返回 HTTP 200、message_id 字符串，未含 ret；本人已在页面确认看到对应唯一编号。因此探针增加“本人可见核对”作为单次实验的独立依据，保留原 unknown，不将人工核对写成平台接纳。后续仍先恢复游标并观察来信，再进行唯一延迟尝试。
